# IDG Dialogue Cards

Interactive web app of the IDG Dialogue Cards: 211 questions across the 5 dimensions and 23 skills of the Inner Development Goals.

- Original questions and card deck: **The Moving Forward**
- Interactive website: **Youth Plus Thailand**
- Based on the [Inner Development Goals](https://innerdevelopmentgoals.org) framework

`index.html` is the whole app in one file (built from the React source). Saved cards and collections stay in each visitor's own browser.
